# 量产阶段纪律（Week 2 起生效——批产流水线协调模型）

> 研究阶段的纪律解决「不确定性」（考证/证伪/更正）；量产阶段的纪律解决「吞吐」
> （并行无冲突、节奏稳定、质量底线不降）。本文=协调者（lead）派发宪法。

## 〇、唤醒协议（每次触发必走——定时器/消息同则）

**核心循环（通过的定义）**：铺量转写 → 对拍+测试 → 独立对抗复核 = 一卡通过。
1. **先析**：git log/status（进度/在产件）+list_agents（负载）+队列态；
2. **后派**：按「转写不停、对拍跟上、复核随行」定派发序——WIP 归属优先续做，
   新转写面次之，复核预位再次；每轮唤醒零空载；
3. **三段齐流**：任一段堵塞=当轮重点处置（转写堵→拆卡/卡点升级；对拍堵→记账/工具件；
   复核堵→并行实例）。

## 一、四车道模型（长驻队列，互斥写路径）

| 车道 | 职责 | 写路径 | 队列源 |
|---|---|---|---|
| A 线（port2） | S 批产（引擎批 S1-S7 降序逐卡） | crates/game-core/src/{引擎域} + oracle/subroutines | 施工卡清单 s1..s7 |
| B 线（porter） | A 批产（区域批 A1-A9）+ 深路径随件 | crates/game-core/src/world/** + frame/（主战场） | 施工卡 A 系+残件表 |
| C 线（decomp） | 证据支援（L2 并案/回归守护/取证包扩面） | tools/oracle/data/status/docs | 卡到簇即响应 |
| D 线（verifier） | 批审（抽样）+关键件全审+回归把关 | docs/rounds/gates | 交付到达即审（事件驱动） |

**并行无冲突三则**：
1. **域树分离**：S 批=引擎域模块 / A 批=world 域模块——新模块为主，天然低碰撞；
2. **共享面通报制**（链规 13 族）：lib.rs/l2ports.rs/memmap/mod.rs/data/status/ 动前一句话+增量式+文件级 pathspec；
3. **瞬态红窗处置**：并行件中间态红=已知类（矩阵表内），谁的破谁快修、他人复跑即绿、不重派不惊慌。

## 二、单卡节拍（固定流程=可预测吞吐）

```
考证（asm 主文档+内容锚+结构互核）→ 两层实施（域化+memmap+shim）
→ L2 到簇并案（s?-pregen golden 三方开启）→ L3/L4 回归（14 案+50 帧）
→ 勾格走级 → 一体 commit（Evidence/Confidence）→ 批审随行（抽样/全审）
```
- 同形卡轻仪式（链规 20）：批内抽检 1-2 件+台账批量笔；新范式/quirk/跨域件=全仪式；
- **无缝续令**：交付收口即带下一件（零 idle 窗）；响应位（C 线）=显式待命即正确态。

## 三、质量底线（不可降）

1. L2 三方（golden=ROM 执行=game-core）逐卡开启——**golden 自 ROM 产出非手推**；
2. L3/L4 回归全绿保持（账面机制显式记缺口，账清转 strict）；
3. D4 保真（bug 保留+注）、Evidence=刚打印输出原文、证据指针可复现；
4. 复审 verdict=pass 才算卡完成（批审抽样≠免审）。

## 四、周节拍（持续迭代的协调者循环）

- **每卡**：无缝续令+批审；
- **每批（5-6 卡）**：回归跑+板面翻+基线平；
- **每周**：进度复盘（吞吐实测 vs 施工图估时）+计划修正（批次边界/优先序调整）；
- **事故即熔断**：卡死/撞车/口径冲突=停手定位（仓内实况定损）→修根因→护栏→再跑。
