# 空壳防护纪律（7 层防护（加固版））+TDD+实现复核（必须保证有效）

> 【2026-10-22 用户裁定】执行（注意 TDD+实现复核（必须保证有效））——彻底避免空壳产出（结构+refs 引证+六步文档（但无逻辑））。

## 核心要求（用户原话）

> 你说你实现了 A，那你实现了 A 的哪些部分，和哪个 asm 对应，全部纪律，复核必跑验证，验证轨迹正确，验证轨迹和实现对等。

## 7 层防护（加固版）

### 第 1 层：事实证据文档（逐项（非笼统））

每个实现必须附事实证据文档：
```
## 事实证据文档：[实现名称]

### 1. 实现内容（逐项（非笼统））
| 实现项 | asm 对应 | 真规则 | 测试 |
|---|---|---|---|
| [实现项 1] | [bank:addr] | [公式形] | [穷举等价证明] |

### 2. asm 对应（逐条（非概括））
- [bank:addr 1]：[asm 例程名]（[写径实证（A 级原文）]）

### 3. 真规则（公式形（零字面特值））
- [实现项 1]：[公式形]（[门条件+状态迁移+写集]）

### 4. 测试（穷举等价证明（全域穷举））
- [测试 1]：[全域穷举]（[边界条件]（[异常路径]））→ [实测输出原文（A 级）]

### 5. 验证轨迹（验证轨迹和实现对等）
- [验证轨迹 1]：[实测输出原文（A 级）]（[与实现对等]）
```

### 第 2 层：复核必跑验证（复核必须实际运行验证）

复核流程（必跑验证）：
1. 检查事实证据文档（逐项（非笼统））
2. **实际运行验证**（cargo test（穷举等价证明））
3. 检查验证轨迹（实测输出原文（A 级））
4. 检查验证轨迹和实现对等（覆盖全部实现）
5. 判定（pass/needs_revision）
任一缺 = needs_revision（拒收）

### 第 3 层：验证轨迹和实现对等（覆盖全部实现）

对等判定：
```
实现项 1 ↔ 验证轨迹 1（穷举等价证明）
实现项 2 ↔ 验证轨迹 2（穷举等价证明）
任一实现项无验证轨迹 = 不对等（拒收）
任一验证轨迹无实现项 = 不对等（拒收）
```

### 第 4 层：复核 11 项（原 9 项+新增 2 项）

①六步流程是否走通？②refs 引证是否实址？③域结构是否正确？④memmap 适配是否正确？⑤shim 写集适配是否正确？⑥测试是否充分？⑦registry 登记是否完整？⑧实现是否包含真规则？⑨测试是否穷举等价证明？⑩复核是否实际运行验证？⑪验证轨迹和实现是否对等？
任一缺 = needs_revision（拒收（空壳（非真实现）））

### 第 5 层：空壳检测（静态+动态+人工）

| 检测方法 | 检测内容 | 判定 |
|---|---|---|
| 静态分析 | `default()` 返回+TODO 注释+平凡操作（`wrapping_add(1)`） | ❌ 空壳 |
| 动态分析 | 测试空转（无实际验证（assert 恒真）） | ❌ 空壳 |
| 人工复核 | 对抗复核（「逻辑是否实现」检查） | ❌ 空壳 |

### 第 6 层：微工单纪律调整（分层纪律）

```
简单任务（≤2 fn（≤30 行））：微工单（单件单动作（先跑后写（禁计划步）（一行收口（长报告禁））））
复杂任务（>2 fn（>30 行））：设计步骤（refs asm 考证→真规则推导→公式形实现→穷举等价证明）
  ——禁止骨架（default() 返回+TODO 注释）
```

### 第 7 层：工具支持（自动化检测）

- lint 规则：检测 `default()` 返回+TODO 注释+平凡操作（`wrapping_add(1)`）
- 测试覆盖率：检测测试空转（无实际验证（assert 恒真））
- registry 完整性：检测 unported! 桩（fail-loud（bank:addr 定位））

## TDD（测试驱动开发）

**TDD 流程**（测试先行（实现后补））：
1. **写测试**（穷举等价证明（全域穷举（边界条件（异常路径））））
2. **跑测试**（cargo test（实测输出原文（A 级）））→ **失败**（实现未完成）
3. **写实现**（真规则（公式形（零字面特值）））
4. **跑测试**（cargo test（实测输出原文（A 级）））→ **通过**（实现完成）
5. **重构**（优化实现（保持测试通过））
6. **复核**（对抗复核（11 项（必跑验证）））

## 实现复核（必须保证有效）

**实现复核流程**（必须保证有效）：
1. **复核必跑验证**（cargo test（穷举等价证明）（实测输出原文（A 级）））
2. **验证轨迹和实现对等**（覆盖全部实现（非部分））
