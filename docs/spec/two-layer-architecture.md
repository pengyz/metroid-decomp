# spec：两层架构——改写与验证（2026-10-15 方法论更正）

> 【更正背景】用户裁定：「6502 指令等价模拟 ≠ 逻辑化 Rust 改写」——
> 验证层（写集契约适配）被误当产品层（sub_F2xx+裸地址形态）。
> 本文件定义**改写形态**与**验证不变式**的接口；方法论总纲以 AGENTS.md 为准，本文件为架构细则。

## 1. 分层定义

```
game-core/src/
├── samus/  enemy/  world/  ui/ …     ← 产品层：业务域模块（struct + method）
│     语义命名；**禁裸地址**（0x400/0x6AF4 这类字面量不许出现在此层）
├── memmap/                            ← 映射层：typed state ↔ RAM/WRAM 字节域
│     地址常量**只活在这里**（含 repr/codec）；注释回指 bank:addr
└── verify_shim/                       ← 验证适配层：域方法 → L2In/L2Out 写集契约
      写集由**状态变更推导**，不手写地址
```

- **产品层**：业务域组织（OOP 风格 struct+method；trait 缝预留不先用）。示例：
  `enemy::EnemySlot::set_attribute(mask)`（F2CA 族语义）、`samus::SamusPhysics::integrate_y()`（int_y）。
- **映射层**：每个 RAM/WRAM 域一个 typed view（`EnemySlots { slots: [EnemySlot;16] }` ↔ WRAM $6AF4-$6BF3），
  encode/decode 集中在此；**地址只此一层**。
- **判定层不变**：golden=ROM 执行 ==（经 shim 的）语义实现——三方裁定/突变矩阵/ratchet/门禁全保留。

## 2. 单元 = 业务域（不再 = 切片）

每单元六步（沿用回路，换了粒度）：
**spec 证据 → 域结构+方法（命名走 data/naming 台账）→ memmap+shim 适配 → L2 案（factory/手写沿用）
→ 矩阵格经适配覆盖（证据指针指向域单元）→ 独立复审**。

- F2CA 族 = `enemy::EnemySlot` 的一组属性/坐标方法（9 个入口=方法集素材），**不是 9 个 sub_F2xx**；
- 切片考证成果（边界定案/语义概要）= 单元的 spec 输入，继续产出价值。

## 3. 验证不变式（重构安全网，一条不松）

1. L2 三方裁定照旧（写集/寄存器终值=对拍面；语义层不感知地址）；
2. 突变矩阵照旧（每单元 ≥2 假想缺陷）；假设台账 A1-A9 照旧消费；
3. **行为钉死 = 结构可换**：语义实现替换切片转写时，同批 L2 案必须持续全绿——
   换形态不许换行为；
4. L3 帧级（S5 起）仍是域间的集成裁判。

## 4. 命名与证据（台账开始消费）

- 语义命名走 `data/naming/` 机械层+语义层台账，**A/B 级+证据字段**（§3 纪律不变，禁伪语义命名不变）；
- 机械名（sub_F2xx）只许存在于 memmap/shim 的注册表注释（回指 bank:addr），产品层代码不出现。

## 5. 迁移路径

- 存量 20 格切片转写 = verify_shim 参考件：逐域被语义实现替换后退役（对拍连续性优先，暂不删）；
- **新工作（task-8 恢复起）按本架构实施**；矩阵登记面不变（covered 判据=域单元+适配对拍全绿）。
