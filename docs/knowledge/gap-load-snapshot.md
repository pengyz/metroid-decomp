# gap-load-snapshot（load_snapshot 缺口（存档格式定义（加载方式）））

## 缺口描述

对拍用例 = ① 输入脚本 + ② 待加载存档 + ③ 对拍时长

**缺口**：待加载存档（load_snapshot）机制缺失

## 缺口内容

### ① 存档格式定义（待定义）
- 游戏状态定义文件（格式）
- 状态字段定义（RAM/寄存器/游戏状态）
- 状态序列化/反序列化

### ② 模拟器加载方式（待定义）
- Mesen2 loadstate（加载存档）
- 状态一致性验证（模拟器状态）

### ③ Rust 加载方式（待定义）
- game-core load_state（加载存档）
- 状态一致性验证（Rust 状态）

### ④ 两边对齐（待定义）
- 状态一致性验证（模拟器 vs Rust 实现）
- 状态差异检测（差异报告）

## 当前状态

- **状态**：缺口（未实现）
- **影响**：无法测试特定游戏状态（只能测试游戏的一幕）
- **优先级**：中（后续增加）
