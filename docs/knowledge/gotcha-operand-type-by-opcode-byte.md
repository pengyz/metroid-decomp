# gotcha：操作数类型以操作码字节为准（45=EOR zp ≠ 49=EOR #imm）

## 现象
把 `45 FF` 误读为 `EOR #$FF`（立即数取反），实为 **EOR 零页 $FF**（与 RAM[$FF] 异或）。
listing 里立即数带 `#`、地址写 `$FF`——但高速读解时极易滑过；`A9 FF` 则是 LDA **#$FF
立即数**（反向陷阱同在）。

## 教训
- 操作数类型由**操作码**决定（45/49、A9/AD、69/6D、E9/ED…），不依肉眼对数值的直觉；
- 零页裸数字记法（`STA 7`）与 `STA $7` 同义，都指 zp 地址；
- 命中案例：sub_F152/sub_F186 尾部 `45 FF`（首版移植误作立即数被三方对拍打回——
  穷举/对拍不救读解错，只有独立复核/逐字节比对能救）；高危同族：F162/F172/F19A 尾部。

## 高危清单（待移植件）
- F19A `B5 B1-B3` = **zp,X**（8 位变址回绕：(0xB1+X)&0xFF）；
- F1CB/F1E7 `79 F5 6A`/`79 F6 6A` = abs,Y 读 WRAM；
- C16D `A9 FF` = 立即数（反向）。
