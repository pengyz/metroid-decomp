# 纪律：不允许继续改写（必须删除重建+补必要函数）

## 用户裁定（2026-10-23）

**不允许继续改写，必须删除重建+补必要函数；当前已改写的部分保留。**

## 背景

- engine/mod.rs（17000+ 行）有大量旧流程产出的错误代码
- 改写已尝试多轮（但问题不断（重复定义+孤立 doc comment+mut 问题））
- 用户裁定「重建」→AI 擅自改为「改写」→违反裁定

## 纪律

1. **不允许继续改写**（禁止对旧代码逐个修复）
2. **必须删除重建**（删除旧代码（按语义重构方案重建））
3. **补必要函数**（外部依赖（测试/其他模块调用））
4. **已改写部分保留**（语义重构方案（30 个逻辑单元））

## 执行步骤

```
① 删除 engine/mod.rs 中的旧代码（地址命名函数（s1_/s2_ 族））
② 保留已改写的语义重构部分（30 个逻辑单元）
③ 按语义重构方案重建（samus/enemy/world/sound/title/render 域）
④ 补必要函数（外部依赖）
⑤ TDD 流程（测试先行→实现→复核）
```

## 触发条件

- 旧代码有大量累积问题（修复一个问题（出现新问题））
- 改写效率低（多轮修复（进展缓慢））
- 用户裁定「重建」
