# gotcha：证据 grep 命令含正则元字符时静默 0——须 `grep -F` 或转义

## 现象
证据字段写 `grep -c '情形；**升级出口（M-C）**'` 之类命令，`**` 在基本正则里是量词
（`*` 重复前元素）**不是字面量**——原样执行静默返回 0，而被声称的事实为真（`grep -F`
即命中）。证据「命令不可复现」与「事实不存在」在输出上不可区分，审计侧只能判失实。

## 教训
- **证据采集命令必须 `grep -F`（固定字符串）或转义元字符**；含 `*`/`[`/`.`/`(` 的中英文
  混排模式尤其易中招（markdown `**`、括号全角半角）。
- 与 d1794af（replace 静默未命中→声称落地）同族镜像：**声称的可复现性本身要可复现**。
- 立规矩：commit Evidence 字段的命令逐条原样跑通才算证据；数字与命令一并抄录。

## 复现
`echo 'a**b' | grep -c 'a**b'` → 0（BRE）；`grep -Fc 'a**b'` → 1。
首例：state-fixture v9（9fecd8a）Evidence 5 条中 2 条原样跑=0（rounds/r4 第 9 轮 F1）。
