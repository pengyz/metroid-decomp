> 螺旋史是「判定权不留静默绿面」的收敛实录——批量阶段的对拍可信度地基。

## 终局验证（第五轮独立复现）

- 竞速双臂（copy 语义 flipper，6000 帧加宽竞速窗口）：**新版 0/25 假 PASS**（14 分歧+11 sha不符）；
  旧版阳性对照 **4/25 假 PASS**——测试器判别力实证（四轮 6/25、修复前复测 2/25、四轮 4/25 同分布族）；
- 撕裂读变体（非原子覆写）：0/25 假绿；
- 回归超抽全覆盖（R3 系 8 项+帧号+回归四连）零回退；E2E/红线/基线/触及面全绿。

## 遗留（裁决不阻断，长期持有）

1. R4-3 断链/符号链接 cache 显式拒（现 fail-loud 无假绿）；
2. R4-5 base≠range 分歧报告 CPU 地址错标（advisory）；
3. R4-6 OSError 裸 traceback（非绿不优雅）；
4. S5 后需双侧重跑 T4/T5 路径（game-core 腿启用时）；
5. 多实例并发双写互踩（TOCTOU 现实触发面，单读已消判定面）。

## 教训（进知识库口径）

- **裁判工具的静默绿面是分层出现的**：口径→校验→对抗性输入→并发——每轮狩猎都从上轮
  「已验证非问题」的边界再挖一层；「狩猎收益递减」须由复审判定不由实施方宣告。
- 竞速测试的测试器本身要过证伪（flipper 移动语义吃源文件→压力归零→假阴性对照）。
