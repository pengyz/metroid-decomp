# north-star —— 长线目标与收敛回路

> 本文件是**稳定的长线目标定义**（不随进度滚动）；滚动计划见 [master-plan.md](master-plan.md)，
> 纪律见 [AGENTS.md](../AGENTS.md)（D1–D7）。制定于 2026-10-14。

## 0. North Star

**Stage A（行为一致）**：用 Rust 写出与《银河战士》(NES USA/NTSC) **行为等价**的 PC 原生实现——
60Hz tick 语义逐帧对齐、原版 quirks 保真保留（BUG-xxx 登记）、差分金字塔 L2–L5 全线绿、
完备性矩阵机械分母全勾且每格带证据。**验收判据绑定矩阵，不绑定测试绿。**

**Stage B（现代化）**：Stage A 验收后启动——宽屏/UI/音频重制/modding 缝/存档现代化。
Stage B 的一切改动不得回溯污染 Stage A 基线（分支或特性开关隔离）。

## 1. 收敛回路（稳态工作单元，每轮六步）

```
┌────────────────────────────────────────────────────────────────────┐
│ ① 制定方案   完备性矩阵取「未覆盖且依赖已清」格 → 任务卡             │
│              （角色 prompt + 范围 + 证据输入 + 完成判据 = 跑哪个门禁）│
│ ② 逐步改写   porter 按 spec 逐规则搬运：                            │
│              先 L2 用例后实现（TDD）；未实现例程一律 unported! 桩    │
│ ③ 验证       gates L1–L4 + 覆盖自校验；首分歧点形态分类路由（pipeline §4.2 现行 6 类）       │
│ ④ 复核       独立审核员证伪复核（实施≠审核；verdict=pass 才算完成） │
│ ⑤ 提交       pre-commit 总闸 + Evidence/Confidence 提交信息 + push  │
│ ⑥ 收敛度量   矩阵 covered 只增不降；ratchet 无回退；剩余缺口显式    │
│              → 报告「下一最优目标」→ 回到 ①                        │
└────────────────────────────────────────────────────────────────────┘
```

硬规则：
- **一次一格**：一个任务卡一个角色一个写路径集；跨层问题按 §4 三问停手换角色，禁止混做。
- **缺口不进调试循环**：unported! 桩爆在 bank:addr = 一张 spec 任务卡；移植错才进 porter 调试。
- **绿 ≠ 完整**：任何一轮不得以「测试全绿」宣布完成；完成 = 该格状态机走到 `已验证` + 复核 pass。
- **证据落仓库**：聊天结论不作数；台账/spec/knowledge/rounds 是唯一产出归宿。

## 2. 进入批量转写的门槛（Gate-in Checklist）

批量转写 = 回路的高吞吐运转。进入前必须全部达成（未达则先补机制，不许带病批量）：

- [ ] **G1** r2 复审 verdict=pass（缺口左移机制与覆盖语义整改闭环）
- [ ] **G2** L2 子程序级 harness 建立：6502 CPU 核直跑 ROM 原字节 → 出入参/写集比对，
      `subroutine-diff` 门禁点亮（缺口探测主力就位）
- [ ] **G3** `crates/` 骨架 + `unported!` fail-loud 桩机制落地（rust-tests 门禁点亮）
- [ ] **G4** 首切片 spec（Samus 移动/跳跃/滚球）+ `constants.md` 逐值带来源
- [ ] **G5** L3 trace-diff 门禁点亮（oracle 场景 trace vs game-core 状态向量）

## 4. 收敛度量（每轮报告固定四行）

1. **矩阵**：`S: covered/total · D: covered/total · B: 场景 n 已对拍 · R: 规则 m 已验证`；
2. **ratchet**：`completeness_cells / rust_test_count / naming_ledger_entries`（只升不降）；
3. **缺口余量**：`unported!` 桩存量、spec 缺口单、未覆盖缺口类清单变化；
4. **下一最优目标**：矩阵中依赖最轻、证据链最短的未覆盖格。

## 5. 风险登记（长线）

| 风险 | 缓解 |
|---|---|
| 时序/边界行为无机械分母（D7 未覆盖类） | 边界用例进 spec 强制章节；L5 流程级场景富矿；BUG 台账显式负空间 |

| 长线漂移（实现逐轮「顺手改进」） | D2/D4 纪律 + 复核抽样式重导 + ratchet 防回退 |
