# findings：$07A0 VRAMStructBufferIndex 中间态捕获核（P28-F1 成对对表）

> 使 $07A0=0xA0（真机同态）」。协议：能见→补捕获工件；不能见→措辞降级「引擎侧同态」。

## 1. 捕获面（写点级=可捕获帧内瞬态；endFrame=帧快照）

## 2. 判定（协议②）

- **写点级（帧内瞬态可捕面）双路径 0 次 0xA0 写**；帧快照 12 份 0 命中——
  「$07A0=0xA0 真机同态」**在捕获面内不可复证**；
- 按协议降级：porter 措辞降为 **「引擎侧同态」（单测支撑，非真机声称）**；
- 保留可能性（C 级）：清零环 Y 填充目标非 $07A0 / 路径未覆盖（如特定重置路径）——
  待引擎侧单测给出写址/写值的具体坐标后可再核（成对端口 C2CA/C37E 对表时一并）。

## 3. 正面收获（供 porter C2CA 单元，A 级）

- $07A0 真实写值域：boot 周期三值 {0,6,12}（各 19 次/300f）；游戏消费态 {33,35,68}
  （=帧快照 21/23/44 同源）——**buffer index 语义的真机写值集**；
- 消费端 C2CA 激活时的索引值=33/35/68 族——与 VRAMStructBufferIndex 建模直接对表。

## 4. 【2026-10-15 定谳·C 级残余闭合（porter 坐标回执）】

C 级两猜（写址非 $07A0 / 路径未覆盖）均否——**第三因定案：源模型错**。
- porter 端口坐标：址=$07A0、值=0xA0、步=boot_pre_spin 清零环（bank07:$C03F-$C055
  clear_pages）——asm 首证 `tya ;A=0` 在环**外**一次性（STA 环写 A=0=零填充），
  端口把 TYA 误读进环内（BNE 回 $C048=STA 而非 $C047=TYA，错位一位）→ 错译「Y 型填充」；
- 本文件写点级捕获（$07A0 无 0xA0 写 + 真机写值域）=**反推定谳的正确面**（写点级
  比帧快照严，抓出模型级 bug——比 L3 对拍早一层）；
- **执行序更正**：「消费端 C2CA 先于生产端 C37E」发现**撤回**（误读产物）——
  清零环已改零填充（porter 侧 38 测全绿），$07A0=0 门放行，**生产端先行=真实序**；
- P28-F1 性质升级：措辞级 → **模型更正案**。
