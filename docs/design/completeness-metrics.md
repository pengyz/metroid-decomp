## 核心原则

**完备性与正确性分离**（扫描治理层设计）——**完备性=覆盖度（有无缺漏）（扫描层）vs
正确性=行为对错（帧一致）（L4 层）——两个独立问题（判据分离）**。

## 完备性指标（Completeness Indicator）

### S/D/B/R 四面覆盖率（百分比）

| 面 | 分母 | 分子 | 覆盖率 | 度量工具 |
|---|---|---|---|---|
| **S 符号面** | 机械分母（completeness_denoms.py） | 已移植符号数 | S_coverage | completeness_denoms.py（已有（S/D 面机械分母）） |
| **D 数据面** | 机械分母（completeness_denoms.py） | 已解析数据表数 | D_coverage | completeness_denoms.py（已有（S/D 面机械分母）） |
| **B 行为面** | 声明性覆盖（已登记场景清单） | 已验证场景数 | B_coverage | 已登记场景清单（声明性覆盖） |
| **R 规则面** | 声明性覆盖（规则声明） | 已声明规则数 | R_coverage | 规则声明（声明性覆盖（AGENTS.md D7（R 规则面完备性不可证））） |

**覆盖率公式（可落码形）**：
```
S_coverage = 已移植符号数 / 机械分母（S 符号面）
D_coverage = 已解析数据表数 / 机械分母（D 数据面）
B_coverage = 已验证场景数 / 已登记场景清单（B 行为面）
R_coverage = 已声明规则数 / 规则声明（R 规则面）
总完备性 = (S_coverage + D_coverage + B_coverage + R_coverage) / 4
```

### 缺口清单（Gap List）

```
缺口清单（A 级实录）：
  S 面缺口：未移植符号清单（completeness_denoms.py 机械导出）
  D 面缺口：未解析数据表清单（completeness_denoms.py 机械导出）
  B 面缺口：未验证场景清单（已登记场景清单比对）
  R 面缺口：未声明规则清单（规则声明比对（AGENTS.md D7（R 规则面完备性不可证）））
```

## 完备性 vs 正确性分离（Completeness vs Correctness Separation）

| 维度 | 完备性（覆盖度） | 正确性（行为对错） |
|---|---|---|
| **问题** | 有无缺漏（覆盖度） | 行为对错（帧一致） |
| **层** | 扫描层（L4 前置） | L4 层（帧对拍） |
| **判据** | 覆盖率（S/D/B/R 四面）+缺口清单 | 帧一致（像素 diff（白名单外全等）） |
| **工具** | completeness_denoms.py（机械分母） | L4 帧对拍（pixel diff） |
| **分离** | **两个独立问题（判据分离）** | **两个独立问题（判据分离）** |

**扫描治理层设计**：完备性=覆盖度（有无缺漏）（扫描层）vs 正确性=行为对错（帧一致）
（L4 层）——**两个独立问题（判据分离）**——先扫完备性再上 L4（完备性不足→L4 diff 被
「缺漏」淹没（而非「行为错」））。
