# 对拍用例 001：进入游戏+角色交互（左右移动+跳跃+射击）
# 用途：验证进入游戏后角色在第一个场景中左右移动，跳跃，射击
# 对拍：模拟器 vs Rust 实现（hash 对比（像素对比））
# 定义：对拍用例 = ① 输入脚本 + ② 待加载存档 + ③ 对拍时长

name case-001-game-start-samus-interaction
frames 1200
snapshot none  # ②待加载存档：none=无存档（上电起跑）；有档写 snapshot <前缀>（≡bundle_load；load_snapshot 消费面缺口记账（后续增加））

# ① 进入游戏（标题→游戏开始）
press 310 start     # 标题按 Start
press 350 start     # 选单按 Start（START GAME）
capture 420 game-in  # 游戏画面（萨姆斯出现）

# ② 角色左右移动
hold 500-550 right  # 向右移动（帧 500-550）
capture 550 after-right  # 向右移动后
hold 600-650 left   # 向左移动（帧 600-650）
capture 650 after-left   # 向左移动后

# ③ 角色跳跃
press 700 a         # 跳跃（帧 700）
capture 720 after-jump   # 跳跃后

# ④ 角色射击
press 800 b         # 射击（帧 800）
capture 820 after-shoot  # 射击后

# ⑤ 组合动作（移动+跳跃+射击）
hold 900-950 right  # 向右移动（帧 900-950）
press 920 a         # 跳跃（帧 920）
press 940 b         # 射击（帧 940）
capture 950 combo-action  # 组合动作后

# ⑥ 对拍结束
endFrame 1200       # 结束帧（对拍点）——≡ capture 1200 end（终端采集点，同帧已有 capture 则去重）

# ③+ 定向采集（2026-10-28 复核整改（diff 归因制））：落地窗/jump-shoot/弹中段
press 710 b        # 跳跃中射击（jump 落地窗前（弹形态定向采集））
capture 715 jump-shoot   # 跳跃中射击帧（弹初段+跳姿）
capture 725 landing-early  # 落地窗（jump 后 25 帧（姿态切换观察））
capture 735 landing-settled # 落地窗（jump 后 35 帧（站姿定型））
capture 810 bullet-midflight # 弹飞行中段（f800 射击后 10 帧）
