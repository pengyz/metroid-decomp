# 对拍用例：长距离左走探针（复现「左走一定距离角色消失」）
# 用途：确认向左走远后角色 sprite 是否消失（emu vs rust 对拍）
name case-leftwalk-probe
frames 800
snapshot none

# 进入游戏
press 310 start
press 350 start
capture 420 game-in

# 长距离左走（帧 440-800，360 帧）
hold 440-800 left
capture 520 left-80
capture 620 left-180
capture 720 left-280
capture 790 left-350

endFrame 800
