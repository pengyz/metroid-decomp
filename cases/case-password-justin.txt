# 对拍用例 case-password-justin：JUSTIN BAILEY 真机密码进场双侧对拍（卡 C）
# 用途：密码场景（标题→菜单→密码输入屏→提交→游戏内 Norfair spawn）Rust vs Mesen 逐采集点像素对拍
# 来源：输入序列=oracle/scenarios/sc-password-justin.txt（卡 A emu 腿验收稿，原样照抄）；
#       出生态契约（卡 A）：$6878=7F/$6879=FF/$69B3=01/InArea $74=11（Norfair）
# 帧号契约：0x18@f505 / 首输入 f540 / 提交 START@f1188 / 游戏内 f1631 / spawn-t4s f1430 / spawn-t20s f2390
# 定义：对拍用例 = ① 输入脚本 + ② 待加载存档 + ③ 对拍时长

name case-password-justin
frames 2600
snapshot none  # ②无存档（上电起跑——密码路径从标题屏进）
watch 002D FC
watch 0320 Cursor1        # 字符游标低位（65 格线性遍历位置）
watch 0321 Cursor2        # 游标行/高位（asm prg0_title.asm L9269 cpy #$0D 线性遍历消费面）
watch 0322 Cursor3
watch 6988 PWByte00       # 密码字节 $6988-$6999（PasswordByte 12 字节面）
watch 6989 PWByte01
watch 698a PWByte02
watch 698b PWByte03
watch 698c PWByte04
watch 698d PWByte05
watch 698e PWByte06
watch 698f PWByte07
watch 6990 PWByte08
watch 6991 PWByte09
watch 6992 PWByte10
watch 6993 PWByte11
watch 0320 PwdTmp         # $0320 密码屏临时面
watch 031e StartGear      # $031E/$031F 起始装备（IsUpload）
watch 031f StartGearHi
watch 6878 GearEnergy     # 出生态契约 $6878=7F（Energy）
watch 6879 GearMissiles   # $6879=FF（Missiles 255）
watch 69b3 JustInBailey   # $69B3=01（JUSTIN BAILEY 魔法字旗标）
watch 0074 InArea         # InArea=11（Norfair）
watch 0106 Health         # Health（$0106）
